What to include in a bug report

  • JB_Drill version.
  • Windows or Android, operating-system version and device model.
  • The smallest sequence of actions that reproduces the problem.
  • A screenshot or short screen recording.
  • If relevant, a minimal .jbdrill file containing the problem.

Please remove athlete names or other unnecessary personal information before attaching a file.

Storage and sync issues

Confirm the folder shown in File → Settings → Storage. For a cloud-backed folder, also check that the provider has completed synchronization and that the file is available offline. JB_Drill does not operate its own cloud service.
