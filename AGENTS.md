# Pokyny pro práci na webu byBartonek

- Před změnou webu si přečti `STYLE_GUIDE.md` a ověř skutečné HTML/CSS dotčené stránky.
- Manuál rozlišuje zdokumentovaný stav kódu od potvrzeného návrhového záměru. Neodvozuj historické důvody pouze z CSS.
- Při každém novém nebo změněném vizuálním rozhodnutí zachyť během práce jeho důvod, zamýšlené použití a dotčené stránky v části „Rozhodnutí a jejich důvody“ souboru `STYLE_GUIDE.md`.
- Když důvod není známý a ovlivňuje navrhované řešení, ověř ho s uživatelem; nevydávej vlastní odhad za jeho dřívější rozhodnutí.
- Zachovej sdílené CSS tokeny a existující komponenty, pokud zadání nevyžaduje změnu systému. Po vizuální změně zkontroluj desktop i mobil.
- Web je statický a publikuje se přímo z repozitáře. Nepřidávej framework, build krok ani závislost bez konkrétního problému, který tím řešíš.
