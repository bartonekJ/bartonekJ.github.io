Some drills are simple lines. Others combine queues, assigned slots, linked actions and a mirrored second phase. This concept update shows how a technical fix can be explained without turning the news page into a changelog wall.

## What was tightened up

- Existing player routes stay intact when slots are assigned.
- Queue progression remains consistent across both colors.
- Mirrored phases use the same general planning rules as the original phase.

The important result is not one repaired drill. It is a planner that behaves more predictably when several systems meet in the same session.
