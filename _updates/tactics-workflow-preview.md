Tactics mode helps explain systems and special-teams decisions without rebuilding the rink for every step. This concept story combines the pieces that make the mode useful in front of a team.

## One sequence, several decisions

Create formation keyframes, move linked groups, label players and control independent puck movement. The same session can move from an overview to the detail that matters at that moment.
