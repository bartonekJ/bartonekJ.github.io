THE IDEA

Think about hockey, not software.

Place players and equipment, then draw the action exactly as you would on paper. JB_Drill infers possession, event links, player colors and common hockey notation wherever it can. Dragging a tool is a one-time action; tapping it keeps the tool active for repeated use.

SMART DRAWING

The rink understands context.

Possession-aware routes

Routes inherit puck state from their player and update when a pass, shot or drop pass changes possession.

Automatic event links

Start and end points snap to players, routes and passes while preserving a coherent action sequence.

Hockey-specific notation

Forward, backward, lateral, pass, shot, saucer pass, endings, edges, transitions and finesse techniques.

Helpful automation

Board passes, obstacle jumps, saucer passes, punch turns and obstacle finesse can be generated from the drawing context.

ANIMATE

Make timing visible.

JB_Drill builds an initial schedule from the event graph, queues and player links. Scrub the timeline, move a player along an existing route, or adjust the speed and wait time of one section. Global speed, symmetric second phases and queue rotation remain editable without redrawing the drill.

TACTICS

Animate formations, not just routes.

Link players into a unit, place formation keyframes and move either an individual or the entire shape. Formation overlays, player labels, puck movement and independent timing make the same canvas useful for breakouts, special teams, defensive structure and lineup presentations.

TRAINING SESSIONS

From library to locker room.

  • Keep multiple drills, layouts, notes, tags, animations and tactics in one .jbdrill file.
  • Search a drill library by age level and hockey category, then add several results to a new session.
  • See the equipment count automatically in Notes.
  • Export selected drills as a multipage PDF or one continuous video.
  • Use a local folder or a folder synchronized by your preferred cloud provider.

PLATFORMS

Tablet-first. Desktop-ready.

The same drill format works on Android tablets and Windows PCs. Touch and pen gestures have mouse equivalents, so a session can move between the bench, office and rink without conversion.
