FIRST FIVE MINUTES

Three rules explain most of JB_Drill.

1

Drag = use once

Drag a player, item, curve, ending or technique from the shelf. After the action, JB_Drill returns to Edit.

2

Tap = keep active

Tap a shelf tool to keep stamping or drawing with it until you choose another mode.

3

Edit directly

In Edit, tap a route to reveal its useful control points. Drag the thing you want to change.

4

Let context help

Start from a player, end on a route or cross an obstacle. The editor links and adapts the action automatically.

A minimal drill

  1. Drag an Offense player onto the rink.
  2. Drag a puck onto the player. The small stick-and-puck marker confirms possession.
  3. Drag Forward + puck onto the rink and draw from the player.
  4. Draw a Shot from the end of the route.
  5. Open Edit → Animate and press Play.

SETUP

Place players and equipment.

Players include Offense, Defense, Goalie and Coach. Items include Puck, Pylon, Tire, Stick on pylons, Stick, Border, Net and a pile of Pucks. Tap a player or item for repeated placement, or drag it for one placement. The currently selected color is used for new color-aware objects.

  • Drag a color onto a color-aware object or action to recolor it.
  • With an object selected, tap a color to apply it.
  • Nets align naturally near the boards. Long equipment can follow the boards while preserving your manual rotation offset.
  • Use Clone to repeat a prepared object with its current orientation.
  • Drag additional pucks onto a player to give the player more pass “charges.” Each pass consumes one.
  • Assign Slots to describe queue order. Use Link Players to group players who act together.

CURVES & EVENTS

Draw the action, not its settings.

Available curves include forward and backward skating with or without the puck, lateral movement, pass, shot and saucer pass. Routes keep hockey notation at a readable size as you change the rink view.

Possession and linking

  • A route started from a player inherits that player's color and puck state.
  • A pass ending on a no-puck route creates a receiving event and changes the following section to puck possession.
  • A pass or shot started from a puck-carrying route branches from that point and updates the following possession state.
  • Players snapped to starts and linked endpoints stay attached while the route is edited.
  • A free pass into space creates a free puck. A later route can collect it.

Endings and techniques

Endings include Arrow, Stop, Screen, Forecheck and Backcheck. Techniques include Drop pass, Mohawk, Transition, Pivot, Inside edge, Outside edge, Forehand, Backhand and finesse shapes such as Deke Left, Deke Right, Toe Drag and Toe Drag Release. Drag an ending anywhere onto a route to change the ending of the relevant section. A technique placed on an endpoint temporarily replaces the visible ending; deleting it reveals the ending again.

Automatic helpers

  • A pass near the boards can become a board pass and target a player or receiving route.
  • A pass over a Border, Stick or Stick on pylons becomes a saucer pass over the obstacle.
  • A skating route over a Stick receives a jump marker.
  • Pylons, tires and stick-on-pylons obstacles can create an editable finesse technique.
  • Sharp qualifying turns can create a removable Punch Turn marker.

EDIT MODE

Only the useful controls are visible.

  • Tap a route to reveal its start, end, techniques and curvature-based control points.
  • Drag a control point to refine the route. Tangents remain automatic unless you deliberately use the hidden tangent gesture.
  • Double-tap a normal control point to remove it.
  • Double-tap and immediately drag between existing points to insert a new point and position it in one motion.
  • Double-tap players, items, techniques, passes, shots or Paint strokes to remove them.
  • Scratch across a route to delete it. A choice appears only when deleting one segment could leave an ambiguous action.
  • Undo and Redo include drawing, object and timing edits.

Deleting a player does not delete the route. The start remains available for a replacement player.

ANIMATE MODE

Build and correct timing visually.

Animate schedules route sections, passes and shots from their event relationships. Press Play or scrub the time slider. Active action sections flash and leave a short fading trail so players can read the current action without the full drawing taking over.

  • Tap a route section on the rink to select the same block on the expanded timeline.
  • Move a player along the existing path to retime that player at the current time.
  • Use the second finger or middle mouse: horizontal changes section speed, vertical changes Wait.
  • On the expanded timeline, drag a block to move it or drag an edge to change its duration.
  • Collapsed timeline is for playback and scrubbing only; section editing is disabled.
  • Use Global Speed to preview or export the drill from 1–500%.
  • Symmetry creates a mirrored second phase; its start can be retimed like other events.
  • Double-tap an animated player to lock or unlock its timing during recalculation.

TACTICS MODE

Keyframe players, puck and formations.

  1. Place and, if useful, Link Players in Edit.
  2. Open Edit → Tactics.
  3. Move one player or the whole linked formation. A keyframe is created at the current time.
  4. Move the timeline, then set the next position.
  5. Use Previous/Next keyframe buttons to edit without accidentally creating another key.
  • Keyframes belong to the whole active formation and can be dragged on the timeline.
  • Double-tap a keyframe to delete it.
  • Double-tap a player to add, edit or clear a label.
  • The puck is animated directly and is not assigned to players in Tactics mode.
  • Drawn routes act as temporary cues: they appear briefly and fade instead of driving the players.
  • Edit the duration at the end of the Tactics timeline.

FILES & DRILLS

One file can hold a complete session.

A .jbdrill file contains multiple named drills. Each drill keeps its own rink background, drawing, notes, tags, Animate timing, Tactics keyframes and global speed.

  • Use + to create a drill and choose Full rink, Half rink or Zone.
  • Drag drill tabs to reorder the session.
  • Use Copy drill and Paste drill to move a complete drill between open files.
  • Use New File for an empty training session.
  • The selected Edit, Animate or Tactics mode and timeline state remain consistent while moving between drills where applicable.

DRILL LIBRARY

Find drills without remembering the file.

The Library indexes drills in the selected storage folder plus the examples bundled with JB_Drill. Filter by age level and category, preview the drawing, notes and tags, select one or several results and choose Add to Session.

  • Age levels: U6 through U18, Junior and Pro.
  • Categories cover warm-up, skills, game, tactics, skating, passing, shooting, special teams, zones, game situations and more.
  • Arrow keys move through results when a keyboard is available.

NOTES & TAGS

Add the information the drawing cannot show.

Notes support selected bold text and adjustable text size. JB_Drill also counts placed training equipment automatically (individual pucks are intentionally excluded). Notes and the equipment summary are included in PDF output.

SHARE

Export a coach-ready session.

Export PDFSelect any drills in the file. Each drill becomes one branded page with its name, rink, notes and equipment summary.
Export VideoSelect any animated drills. They are rendered in session order as one video with drill titles and each drill's Global Speed.
Export .jbdrillSaves the editable source session, including drawings, logic, notes, tags, animation and tactics.

STORAGE & SYNC

You choose where the files live.

Open File → Settings → Storage and choose the folder that should directly contain your .jbdrill files. On Android this can be a local folder or a folder exposed by Google Drive. On Windows it can be any accessible folder, including a folder synchronized by Google Drive for desktop.

Choose the same cloud folder on both devices to work with the same files. Sync speed is controlled by the storage provider, not JB_Drill.

TROUBLESHOOTING

When something does not look right.

A file is missingOpen Settings and confirm the selected folder. If it is cloud-backed, verify that the provider has finished syncing.
Library opens slowly onceThe first scan reads drill metadata and builds previews. Keep the Library open while “Loading data” is shown; later openings use the cache.
I cannot edit timeline blocksExpand the Animate timeline. Editing is intentionally disabled in collapsed mode.
A route draws with the puckCheck the player's puck markers and incoming events. Each available puck allows another puck-carrying action or pass.
Gesture is not recognizedKeep the first pointer down before adding the second finger. Some tablet stylus settings block touch while the pen is hovering.
I found a repeatable bugSave the smallest useful .jbdrill example and send it with the app version and device model to support@bybartonek.com.
