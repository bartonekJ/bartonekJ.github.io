LICENSES

One paid subscription. Both platforms.

Personal or Pro can be purchased on either Google Play or Microsoft Store. Link the other installation to the same license—there is no need to buy a second subscription just to use both Android and Windows. Every linked installation counts toward the plan's device limit.

  • Free

    Up to 2 sheets in a session, watermarked PDF, MP4 and JB_Play exports, and 1 active device.

  • Personal

    No plan limit on sheets, no export watermark, and up to 3 active devices.

  • Pro

    No plan limit on sheets, no export watermark, and up to 30 active devices.

Free uses one editable FreeSession file and the Included drills in the Library. Paid plans can open other saved sessions.

LINK ANOTHER DEVICE

Bring the license along.

  1. On the device with the active Personal or Pro subscription, open Settings > License & devices and create a linking code.
  2. On the other Android tablet or Windows PC, enter that code under Link this device.
  3. Confirm that the paid plan appears on the new installation.

Linking transfers license access, not drill files. To work with the same files on both devices, use a shared Storage folder through a cloud provider of your choice.
